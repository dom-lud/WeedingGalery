# Frontend

## Cel dokumentu
Krótka informacja o aktualnym stanie frontendu w repozytorium.

## Stan obecny
- Frontend jest wczesnym szkieletem React + TypeScript + Vite.
- Zależności zawierają Material UI, ale docelowa architektura widoków, routingu i komponentów domenowych nie została jeszcze wdrożona.
- Obecny `src/App.tsx` ma charakter startowy i nie odzwierciedla jeszcze domeny produktu.
