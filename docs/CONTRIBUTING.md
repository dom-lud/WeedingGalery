# Contributing

## Cel dokumentu
Opisuje zasady współpracy przy rozwoju repozytorium.

## Status dokumentu
- Status: draft
- Zakres: standard kontrybucji
- Ostatnia aktualizacja: 2026-07-12

## Stan obecny
- Dokument definiuje proces dla przyszłych zmian.

## Stan docelowy
- Każda zmiana jest mała, uzasadniona, przetestowana i udokumentowana.

## Zasady
- Pracuj w małych, spójnych zakresach.
- Najpierw czytaj dokumentację i ADR.
- Nie mieszaj refaktoryzacji niezwiązanej z zadaniem.
- Aktualizuj dokumentację razem ze zmianą techniczną.
- Zgłaszaj decyzje architektoniczne przez ADR.
