# Checklist Incydentu

## Cel dokumentu
Lista kontrolna dla analizy i obsługi incydentu.

## Status dokumentu
- Status: draft
- Zakres: incident checklist
- Ostatnia aktualizacja: 2026-07-12

## Stan obecny
- Checklista jest dokumentem wspierającym reakcję na incydent.

## Stan docelowy
- Każdy incydent ma uporządkowany tok reakcji i analizy.

## Lista kontrolna
- [ ] Incydent został sklasyfikowany.
- [ ] Zakres wpływu został oszacowany.
- [ ] Działania ograniczające zostały wdrożone.
- [ ] Zebrano logi, audyt i kontekst techniczny.
- [ ] Rozróżniono fakty od hipotez.
- [ ] Oceniono wpływ na bezpieczeństwo i prywatność.
- [ ] Oceniono wpływ na backup, storage i monitoring.
- [ ] Zidentyfikowano przyczynę źródłową albo jawnie oznaczono jej brak.
- [ ] Zdefiniowano działania naprawcze krótkoterminowe.
- [ ] Zdefiniowano działania zapobiegawcze długoterminowe.
