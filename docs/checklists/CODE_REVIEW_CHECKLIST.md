# Checklist Code Review

## Cel dokumentu
Lista kontrolna dla review zmian kodu i dokumentacji technicznej.

## Status dokumentu
- Status: draft
- Zakres: code review checklist
- Ostatnia aktualizacja: 2026-07-12

## Stan obecny
- Checklisty review nie są jeszcze częścią formalnego procesu PR.

## Stan docelowy
- Review jest powtarzalne i skupione na rzeczach technicznie istotnych.

## Lista kontrolna
- [ ] Zmiana jest poprawna funkcjonalnie.
- [ ] Kod jest czytelny i utrzymywalny.
- [ ] Zakres zmiany jest adekwatny do zadania.
- [ ] Architektura i podział modułów są zachowane.
- [ ] Nie pojawia się zbędna duplikacja.
- [ ] Obsługa błędów jest poprawna.
- [ ] Logowanie i audyt są uwzględnione, jeśli dotyczy.
- [ ] Testy są adekwatne.
- [ ] Dokumentacja została zaktualizowana.
- [ ] Bezpieczeństwo i ownership zostały sprawdzone.
