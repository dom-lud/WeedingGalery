# Dostępność

## Cel dokumentu
Opisuje minimalne wymagania dostępności dla frontendu.

## Status dokumentu
- Status: draft
- Zakres: dostępność UI dla stanu docelowego
- Ostatnia aktualizacja: 2026-07-12

## Stan obecny
- Wymagania nie są jeszcze odwzorowane w implementacji.

## Stan docelowy
- Frontend spełnia podstawowe praktyki WCAG dla krytycznych ścieżek produktu.

## Wymagania
- Pełna obsługa klawiatury dla formularzy, modali i galerii.
- Widoczne focus states.
- Alternatywne opisy dla elementów znaczących.
- Odpowiedni kontrast kolorów.
- Komunikaty błędów powiązane z polami formularzy.
- Odtwarzacz wideo i lightbox bez pułapek focusu.

## Priorytetowe ścieżki
- Rejestracja i logowanie
- Wejście do galerii publicznej
- Upload plików
- Moderacja materiałów
- Pobieranie galerii
